Analysis code for a single-cell RNA-seq study of cerebrospinal fluid and PBMCs in an inflammatory CNS condition and controls: ambient-RNA correction, clustering, differential abundance, pseudobulk differential expression by diagnosis and disease severity, gene sets, cell-cell communication and trajectories.

- **`analysis/`**: R Markdown notebooks
- **`R/`**: helper functions
- **`metadata/`**: templates for expected input tables
